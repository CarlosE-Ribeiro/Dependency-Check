CVE-2015-6420 7.5 HIGH A CVE-2015-6420 é uma vulnerabilidade crítica de desserialização que afeta diversos produtos Cisco que utilizam a biblioteca Apache Commons Collections, especificamente a versão 3.2.1. Atacantes remotos podem explorar esta falha ao enviar objetos Java serializados maliciosos. Isso permite a execução de comandos arbitrários no sistema alvo. A vulnerabilidade reside na manipulação insegura de objetos serializados pela biblioteca ACC. A principal solução é atualizar a dependência Apache Commons Collections para uma versão que não seja vulnerável, como a versão 3.2.2 ou 4.1 e superiores. Para os produtos Cisco afetados, é fundamental aplicar as atualizações de software ou patches de segurança fornecidos pelo fabricante. Como medida adicional, pode-se considerar a implementação de filtragem de desserialização para permitir apenas a desserialização de classes conhecidas e seguras.
