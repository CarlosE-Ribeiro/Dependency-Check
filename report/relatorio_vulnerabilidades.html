CVE-2015-6420 7.5 HIGH A CVE-2015-6420 é uma vulnerabilidade de desserialização que afeta a biblioteca Apache Commons Collections, incluindo a versão 3.2.1. Esta falha permite que atacantes remotos executem comandos arbitrários. Isso ocorre ao enviar objetos Java serializados maliciosos para aplicações que utilizam a biblioteca vulnerável. Diversos produtos Cisco foram impactados por esta vulnerabilidade, abrindo portas para controle indevido do sistema. A principal solução é atualizar a biblioteca Apache Commons Collections para uma versão corrigida, como 3.2.2 ou superior. Recomenda-se aplicar quaisquer patches ou atualizações de software fornecidos pelos fabricantes dos produtos que utilizam essa dependência. Como medida de mitigação, pode-se implementar restrições de desserialização, permitindo apenas classes de fontes confiáveis ou aplicando o uso de listas de permissão (whitelisting) para a desserialização de objetos.
